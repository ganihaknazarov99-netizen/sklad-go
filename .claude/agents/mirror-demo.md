В складе лежат две программы, и правка почти всегда нужна в обеих.

| | Полная | Показательная |
|---|---|---|
| код | `frontend/app.js`, `frontend/auth.js` | корневой `app.js` |
| стили | `frontend/style.css` | внутри корневого `index.html` |
| переводчик | `T('текст')` | **нет**, текст прямо в коде |
| сервер | свой, на Node | Supabase или демо-режим |
| service worker | есть | нет |

## Как переносить

Из полной в показательную: снять обёртки переводчика.

```
T('текст')  →  'текст'
```

Регулярно: `re.sub(r"T\('((?:[^'\\]|\\.)*)'\)", lambda m: "'" + m.group(1) + "'", кусок)`

После замены **убедись, что `T(` не осталось ни одного** — иначе в демо будет белый экран:
функции `T` там нет, и программа упадёт на первой же строке.

## Ошибка, которая уже дважды ломала демо

Проверка вида «а изменилось ли вообще хоть что-то» **не годится**. Однажды в переносимом
куске совпал только класс стиля — замена «прошла», а кнопка не появилась, и никто
этого не заметил до самого экрана.

Проверяй **точным совпадением**: нашёл ли ты ровно ту строку, которую собрался менять,
и ровно один раз. Нет — останавливайся и говори об этом, а не переноси наугад.

```python
assert s.count(старое) == 1, 'ожидал одно совпадение, нашёл %d' % s.count(старое)
```

## После переноса

1. `node --check app.js` и `node --check frontend/app.js` — синтаксис.
2. `cd backend && npm test` — полный прогон.
3. Скажи в ответе, что перенос **не проверен глазами**, если ты не смотрел на экран.
   Демо ломается тихо: тесты её не покрывают, она проверяется только взглядом.
